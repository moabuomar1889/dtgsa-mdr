# Cover Designer User Guide

Date: 2026-07-29

## Access

Users with template-management permission open `Templates` and select
`Open visual cover designer`.

## Create a Draft

1. Enter a stable template code and name.
2. Choose organization, client, project, document type, or discipline scope.
3. Select the matching scope value when the scope is not organization.
4. Optionally clone a prior version.
5. Create the draft.

## Design

Use the element library to add layout content. Drag elements on the
resolution-independent paper canvas. Hold Shift for multi-select. Grid
snapping and the center guide assist alignment. The inspector accepts exact
relative coordinates and sizes.

The toolbar provides zoom, grid, lock, duplicate, delete, bring-to-front,
center alignment, undo, redo, preview, save, and publish operations. Locked
elements cannot be dragged or deleted.

## Validate and Publish

Preview with sample data, inspect the validation panel, and save the draft.
Publication requires valid geometry and bindings plus a formal Prepared By
Manager signature box. Published versions are immutable. Clone a published or
superseded version to make a change, then publish the new draft.

## Client Response Legend

Add a client response legend element when the cover requires it. At generation
time the renderer reads the project's published response-code set, including
its exact external codes and wording. Codes are not restricted to numbers or a
fixed 1-5 list.
