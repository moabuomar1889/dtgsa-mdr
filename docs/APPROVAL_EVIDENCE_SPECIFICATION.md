# Approval Evidence Specification

Approval evidence canonically binds the immutable Google subject, employee and
role snapshots, document/revision, Main File and Package Hash, workflow cycle,
step and review session, decision, declaration hash, sorted comment
references, recent authentication, request fingerprints, decision time, and
signature appearance version.

Phase 6 provides the contract but does not route the legacy workflow through
it. Existing Signature Events remain visible, not file-bound, not sealed, and
legacy-unverifiable.
