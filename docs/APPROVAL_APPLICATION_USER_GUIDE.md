# Approval Application User Guide

Date: 2026-07-29

## Inbox

The inbox groups active, upcoming, returned, clarification, completed,
delegated, and overdue steps. Search covers document, revision, project,
client, step, and role. Only assignments within the current user's project
scope are returned.

## Review

Select a step and open the exact controlled package. Confirm the visible
document number, revision, and Package Hash. Use page navigation, zoom, fit
controls, and authorized download. The activity panel truthfully lists rendered
pages and approximate active time.

Accept the responsibility declaration only after completing the review. If the
Package Hash changes, the old session is revoked and cannot authorize a
decision.

## Comments and Decisions

Create general, page, area, or selected-text findings. Mark a finding blocking
when correction is mandatory. Blocking closure requires independent
verification.

Available decisions are Approve and Sign, Approve with Non-Blocking Comment,
Request Clarification, Return for Revision, Reject, DC Validate, and DC Return.
The server verifies assignment, exact-package review, recent authentication,
declaration, blocking conditions, role policy, state version, and idempotency.

Returns require responsibility and due-date details. Prior decisions remain in
history; corrected content starts a new package and cycle.
